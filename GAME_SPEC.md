# Tetris and Network Specification
This is a simplified placement-based Tetris variant, not full modern guideline Tetris.
Board 20x10, row 0 top, column 0 left. Pieces I,O,T,S,Z,J,L with normalized clockwise rotations and duplicates removed. Seeded NumPy PCG64 seven-bag. No hold, preview, spins, tucks, wall kicks or horizontal movement after descent. For each current piece, engine enumerates legal rotation/x placements, hard-drops, locks and clears rows. Game ends on top-out or 1,000 placements. Candidate order rotation then x; ties choose first.
Network input: 205 float32 values. Indices 0:200 are flattened post-placement/post-clear binary board occupancy. Indices 200:205 are one-hot line-clear count 0..4. Network is h1=ReLU(x@W1+b1), W1(205,128),b1(128,); h2=ReLU(h1@W2+b2), W2(128,32),b2(32,); score=h2@W3+b3, W3(32,1),b3(1,). Higher score wins. 30,529 float32 finite parameters. No seed, bag, future piece, hold or piece identity is given to the network. Game score per placement: 0,100,300,500,800 for 0..4 lines, multiplied by current level; level increases every 10 lines. Primary objective is maximize mean official game score over practice batches. Other metrics are diagnostics.
