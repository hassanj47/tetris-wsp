# Tetris WSP — isolated Astra Author v1 workspace

This is a cloud-only, isolated authoring workspace. It intentionally contains no game engine, policy implementations, baseline code, replay recordings, or evaluation tools.

## Read first
1. `AGENTS.md`
2. `ASSIGNMENT.md`
3. `RULES.md`
4. `author_brief/BRIEF.md`

## Goal
Directly author the fixed 205 → 128 → 32 → 1 network in weight space. This is not a training task. The initial attempt must be completed without gameplay or evaluation feedback.

## Dependencies
Python 3.11+ and NumPy 2.x. See `requirements.txt`.

## Completion
Commit the five required artifacts listed in ASSIGNMENT.md to this branch. Do not merge or create a PR.
