# Tetris WSP — Astra Discovery v3
Isolated feedback-guided WSP experiment. Astra starts from zero-initialized weights, independently constructs a neural placement-scoring policy, plays at most three fixed 20-game practice batches, inspects aggregate feedback and three diagnostic replays per round, then directly edits weights between rounds. No prior WSP artifacts, baselines, heuristic coefficients or expert examples are supplied. Read ASSIGNMENT.md, DISCOVERY_PROTOCOL.md, GAME_SPEC.md and RULES.md. All work occurs in Codex Cloud. Final artifact will be evaluated separately on held-out seeds.
